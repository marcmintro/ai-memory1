# Entscheidungen

Neue Entscheidungen unten anfügen. Nichts löschen: Eine überholte Entscheidung
bekommt den Vermerk „Ersetzt durch E-xxx“.

Vorlage:

```
## E-xxx: Kurzer Titel
- Datum: JJJJ-MM-TT
- Entschieden von: Name
- Entscheidung: Was gilt jetzt?
- Begründung: Warum?
- Status: gültig | ersetzt durch E-yyy
```

## E-001: Alles im Repo ai-memory1 festhalten
- Datum: 2026-11-10
- Entschieden von: Marc
- Entscheidung: Entscheidungen, Aufgaben und Fortschritt des Projekts werden
  im Repository `marcmintro/ai-memory1` im Ordner `projekt-gedaechtnis/`
  dokumentiert.
- Begründung: Marc möchte, dass alles aufgezeichnet wird und nichts verloren
  geht, auch über verschiedene Sitzungen hinweg.
- Status: gültig

## E-002: Codex als manuelle Ausweichlösung
- Datum: 2026-11-10
- Entschieden von: Marc
- Entscheidung: Wenn Claudes Limit erreicht ist, setzt Marc Codex selbst auf
  dieses Repository an und arbeitet dort weiter. Ein automatischer Wechsel ist
  nicht möglich.
- Begründung: Weil der gesamte Kontext in `projekt-gedaechtnis/` steht, kann
  jedes Werkzeug die Arbeit ohne Kontextverlust fortsetzen.
- Status: gültig

## E-003: Gedächtnis in eigenem Unterordner, auf Deutsch
- Datum: 2026-11-10
- Entschieden von: Claude (auf Marcs Freigabe „mach das so“)
- Entscheidung: Die Gedächtnis-Dateien liegen in `projekt-gedaechtnis/`
  statt im Hauptordner, und sie werden auf Deutsch geschrieben.
- Begründung: Der Hauptordner enthält bereits README, AGENTS.md und den
  Quellcode des Werkzeugs ai-memory. Ein eigener Ordner überschreibt nichts
  davon. Ein kurzer Verweis ganz oben in `AGENTS.md` sorgt dafür, dass Claude
  und Codex den Ordner finden.
- Status: gültig
